# Aqua Monitor 4 — Android

Testowa aplikacja Android WebView wyświetlająca https://akwaria.networkserwis.pl.

## Budowanie
Wejdź w Actions → Build Android APK → Run workflow. Po zakończeniu pobierz artifact AquaMonitor4-debug-apk.

## Bezpieczeństwo
Nie przechowuj w repozytorium haseł, tokenów ani kluczy API. Ta aplikacja nie zmienia serwera i nie steruje bezpośrednio urządzeniami. Debug APK służy wyłącznie do testów. Produkcyjne wydanie wymaga własnego podpisu i testów.
